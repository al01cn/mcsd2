# 2026-08-27

## 音频包导入进度弹窗

为 MCSD2 音频包导入流程加入「导入状态弹窗」，解决点击导入后无反馈、用户可能重复点击导致重复导入的问题。

改动：
- `app/ui/create-project-modal.tsx`
  - 新增类型：`ImportPackPhase` / `ImportDetectedPack` / `ImportPackProgress` / `ImportProgressCallback` / `OnImportAudioPack`。
  - `ImportAudioPackModal` 增加 `idle / importing / success / error` 四态，导入中展示状态文字、进度条、检测到的版本信息（平台 / 资源包版本 Pack Format / 音频包版本 / 版本类型 / 游戏版本），导入中禁用关闭与提交按钮，成功自动关闭，失败可重试。
  - `onImport` 签名改为 `OnImportAudioPack`（可选 onProgress 回调）。
- `app/ui/desktop-workspace.tsx`
  - `readAudioPackArchive` 增加 `onProgress` 回调，分阶段上报：reading → detecting（含 detected 版本信息）→ extracting（逐文件百分比）→ finalizing。
  - `importProject` 透传 `onProgress`。
- `app/ui/mobile-workspace.tsx`
  - `onImportProject` 类型改为 `OnImportAudioPack`（移动端复用同一套导入弹窗）。
- `app/globals.css`
  - 新增 `.import-pack-progress` / `.import-pack-detected` / `.import-pack-result` 等样式，复用 `--modal-*` 变量与 `export-spin` 动画。

验证：`npx tsc --noEmit` 与 `npx eslint` 均零错误零警告。

关键点：导入解压解析在 `readAudioPackArchive` 内完成，检测信息在 `fallbackProject` 构建后回调（percent 28），音频文件逐个解压时按比例推进进度（30→90）。

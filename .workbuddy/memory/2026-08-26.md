# 2026-08-26

## 改动：手机端事件文件夹/音频长按改为手机操作弹窗（修改/更改/移除）

**需求**：`novice-event-manager` 里事件文件夹与音频文件长按，改为带标题+取消的底部操作弹窗（action sheet），实现「修改、更改、移除」。

**实现**（`app/ui/novice-event-manager.tsx` + `app/globals.css`）：
- context menu（`.novice-context-menu`，touch 时 `.is-touch` 底部弹窗）渲染改造：
  - touch 时加标题行 `.mobile-action-sheet__header`（folder 显示 `eventLabel(eventName)`；audio 显示 `audio.name`）。
  - touch 时底部加「取消」按钮（`.is-cancel`，居中灰底，点击 `setContextMenu(null)`）。
  - 菜单项：folder = 修改（自定义→重命名 `setEditingEvent`；原版→更换原版 `setReplaceEvent`）+ 移除（`onDeleteEvent`）；audio = 修改（`editAudioSettings` 聚焦字幕）+ 更改（`FolderInput` 图标，`setMovingAudioIds` 移动）+ 移除（`removeAudioFromEvent`，仅非未分组）。
- 文案：`replaceItem`（替换）改名 `changeItem`（更改）；新增 `cancel`（取消/Cancel）。
- 图标：audio「更改」由 `RefreshCcw` 改为 `FolderInput`（语义更贴合移动到文件夹）。
- CSS：`.novice-context-menu.is-touch button.is-cancel`（居中、灰底、上边框分隔）；`.novice-event-folder` 与 `.novice-audio-item` 加 `-webkit-touch-callout`/`user-select: none` 防 iOS 长按系统 callout/选中。

**约定**：`novice-event-manager` 的长按用 `onPointerDown`(非 mouse) + `longPressRef` 450ms 定时器 → `openTouchActionSheet`（`contextMenuSource="touch"` → `.is-touch` 底部弹窗）；标题与取消仅在 touch 源渲染，桌面右键菜单（mouse 源）保持简洁。类型检查与 lint 均通过。

3. **版本号 + 更新日志 2.1.0**（2026-08-26）：`package.json` version → `2.1.0`；`app/layout.tsx` JSON-LD `softwareVersion` → `2.1.0`；`lib/update_logs.ts` 新增 `"2.1.0"` 条目（移动端音频滚动容器/长按操作弹窗/步骤导航图标按钮/弹窗层级与日志区域修复）。
